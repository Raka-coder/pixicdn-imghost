# Tahap 2 Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Register/login/logout + reset via recovery code, session aman.

**Architecture:** PHP 8.2 native, PDO prepared, bcrypt cost 12 untuk password + recovery code, `session_regenerate_id(true)` setelah login/register, cookie `httponly/secure/samesite=Lax`, CSRF per form. Sesuai `docs/prd.md` §3.2.6-3.2.11, `docs/architecture.md` §4.4, `docs/rules.md` §4.1/4.4/4.6.

**Tech Stack:** PHP 8.2 native, MariaDB 11 (`users`, `password_resets`), Tailwind v4 CDN, no framework.

**Spec:** `docs/prd.md` §3.2.6-3.2.11 + decision Recovery Code (Tahap 1 approval).

## Global Constraints

- `declare(strict_types=1)` + file header di semua PHP.
- Username: 3-30 char, `[a-zA-Z0-9_]`.
- Password: min 8 char.
- Recovery code: 8 char `[A-Z2-9]` tanpa O/0/I/1, tampil sekali, simpan bcrypt.
- `password_hash(..., PASSWORD_BCRYPT, ['cost'=>12])`, `password_verify`.
- Session name `PIXICDN_SESSION`, regenerate setelah login/register.
- Semua query prepared, semua output `sanitize()`.
- Response forgot sama untuk user ada/tidak (no enumeration).
- Bahasa UI Indonesia.

## Review Focus

- Recovery code tidak pernah disimpan plain, hanya hash.
- Session fixation: regenerate wajib setelah auth sukses.
- CSRF token wajib di register/login/forgot/reset.
- Forgot tidak bocorkan user ada/tidak via timing/pesan.
- Token reset SHA-256 64 hex, expire 1 jam, sekali pakai.
